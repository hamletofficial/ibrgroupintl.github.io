Hamlet for Windows

Use Hamlet as a Windows 10 or 11 desktop application, with desktop features designed to complement the Hamlet workspace.

Official release download

Hamlet v1.04.02 is the latest published Windows release. Download the installer directly from the official release assets, and keep the matching SHA-256 file so you can verify the download before running it.

Installation instructions

  1. Download hamlet-Setup-1.4.2.exe using the official v1.04.02 download link above.
  2. Download SHA256SUMS.txt from the same release.
  3. In PowerShell, run Get-FileHash .\hamlet-Setup-1.4.2.exe -Algorithm SHA256 from the folder containing the installer. Compare the resulting hash with the entry for that exact filename in SHA256SUMS.txt. The values must match exactly.
  4. If the checksum does not match, do not run the installer; delete it and download it again from the official release.
  5. Run the installer and review any Windows security or publisher prompts before proceeding. Do not bypass a warning if you cannot establish that the file is authentic.
  6. Open Hamlet for Windows and sign in using your usual Hamlet account.

Security and updates

The installer is distributed with a SHA-256 checksum. Checksum verification helps confirm file integrity, but it does not independently establish publisher identity. Publisher code signing and secure automatic updates remain planned improvements. Check the official release page for the latest version and its matching checksum before installing an update.
