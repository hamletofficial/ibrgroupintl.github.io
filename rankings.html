A transparent leaderboard recognising brokers who consistently convert commercial property opportunities into completed deals. Rankings use average completed deal value per broker account, not the size of an unclosed pipeline.

Leaderboard

Fair-comparison note: The leaderboard uses aggregate statistics published on a broker's public member profile. Private profiles and individual deal records are not exposed by this page. If no aggregate statistics have been published yet, the page will say so rather than inventing results.

How rankings are calculated

Primary metric: mean completed deal value per broker account.

Average closed deal value = total value of deals marked Closed ÷ number of deals marked Closed. This rewards brokers who repeatedly complete material transactions, while excluding speculative pipeline values that may never convert. Total closed value and closure count are available as secondary sorting options to give context and reduce overreliance on one headline number.

Only aggregate fields published to a member's public profile are displayed. A trusted backend should calculate and update those fields from confirmed closed deals; browser-side code must not treat self-reported figures as verified.
