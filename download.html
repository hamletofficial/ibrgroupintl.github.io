Installation instructions

  1. Download hamlet-Setup-1.4.0.exe using the official v1.04 download link above.
  2. Download SHA256SUMS.txt from the same release.
  3. In PowerShell, run Get-FileHash .\hamlet-Setup-1.4.0.exe -Algorithm SHA256 from the folder containing the installer. Compare the resulting hash with the entry for that exact filename in SHA256SUMS.txt. The values must match exactly.
  4. If the checksum does not match, do not run the installer; delete it and download it again from the official release.
  5. Run the installer and review any Windows security or publisher prompts before proceeding. Do not bypass a warning if you cannot establish that the file is authentic.
  6. Open Hamlet for Windows and sign in using your usual Hamlet account.

Security and updates

Publisher code signing and secure automatic updates are planned improvements. Until a release explicitly confirms signing, do not assume the installer is code-signed. Never bypass a Windows security warning solely because a file is labelled Hamlet.

This installer is distributed with a SHA-256 checksum, but checksum verification alone does not establish publisher identity. Publisher code signing and secure automatic updates remain planned improvements. Check the release page for the latest stable version and its matching checksum before installing an update.
