Hamlet for Windows

Use Hamlet in a Windows-friendly desktop application, with desktop features designed to complement the Hamlet workspace.

Official release download

Download the installer from the official GitHub Releases page. Only use a release that includes its published SHA-256 checksum and release notes. If no installer is listed yet, the next public package has not been published.

View official releases Source repository

Installation instructions

  1. Download the Windows installer from an official release.
  2. Check the release notes and compare the installer’s SHA-256 hash with the checksum published for that exact release.
  3. Run the installer and review any Windows security or publisher prompts before proceeding.
  4. Open Hamlet for Windows and sign in using your usual Hamlet account.
  5. Keep the installer and checksum for your records until the application has been verified on your device.

Security and updates

Publisher code signing and secure automatic updates are planned improvements. Until a release explicitly confirms signing, do not assume the installer is code-signed. Never bypass a Windows security warning solely because a file is labelled Hamlet.

Future releases should publish the version number, release notes, SHA-256 checksum and signing status together. Automatic updates should validate signed update metadata and package integrity before installation.
