Install and verify

  1. Download the installer and the matching SHA256SUMS.txt file from the same release.
  2. In PowerShell, run Get-FileHash .\hamlet-Setup-1.4.2.exe -Algorithm SHA256 in the folder containing the latest installer. If using an older version, replace the filename with that version’s exact installer name.
  3. Compare the computed hash with the entry for the same filename in SHA256SUMS.txt. The values must match exactly.
  4. If the checksum does not match, do not run the installer. Delete it and download it again from the official GitHub release.
  5. Review Windows security or publisher prompts before proceeding. Do not bypass a warning if you cannot establish that the file is authentic.
i

Security and update guidance

SHA-256 verification checks file integrity; it does not independently prove publisher identity. The Hamlet installer is not yet code-signed, and secure automatic updates remain planned. Check the release notes and checksum for the exact version before installing.
